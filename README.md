# KZTB — Кировский Завод Теплоблоков

Современный корпоративный сайт и каталог для завода по производству энергоэффективных теплоблоков (Экоблок, Иноблок).

## 🌍 URL проекта

- **Тестовая версия (GitHub Pages):** [https://josephfareez.github.io/kztb-eco/]
- **Основной домен:** https://kztb.ru/

## 🛠 Технологии

- Чистый HTML5 / CSS3 / Vanilla JavaScript (Без тяжелых фреймворков для максимальной скорости загрузки).
- Кастомный калькулятор расчетов (JS) на основе заводских формул из Excel.
- Изображения оптимизированы в формат WebP с использованием `loading="lazy"`.
- SEO: Внедрена микроразметка Schema.org, Open Graph и Twitter Cards.

## 📂 Структура проекта

- `index.html` — Главная страница (презентация, услуги)
- `catalog.html` — Полный прайс-лист на все виды блоков и фасадов
- `calculator.html` — Интерактивный калькулятор расчета сметы
- `all-projects.html` — Галерея реализованных объектов с разделением по годам
- `privacy.html` — Политика конфиденциальности
- `/css/` — Таблицы стилей
- `/js/` — Логика калькулятора, слайдеров и мобильного меню
- `/assets/images/` — Логотипы, иконки и фото проектов

## 📧 Обработка заявок (Формы)

На этапе тестирования формы на сайте отправляются через сервис **Formspree** (принимает JSON на почту `kztbt@mail.ru`).
**Важно при релизе:** При переносе сайта на основной хостинг (Apache/Nginx с поддержкой PHP) необходимо вернуть в
атрибуты `action` файлов HTML скрипт `mail.php` и вернуть стандартный `fetch` в файле `calculator.js`.
