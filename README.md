# ЭКОБЛОК — самостоятельный HTML/CSS/JS сайт

Главная страница сделана без Tilda по предоставленному дизайну. Органические изгибы реализованы CSS: ellipse/clip-path/border-radius и псевдоформы.

## Структура
- index.html
- css/style.css
- js/main.js
- assets/images/ — место для локальных фотографий

## Сохранённая структура и факты
Собственное производство, контроль качества, доставка, тёплый дом; каталог из 4 видов; современное производство; 20+ лет; современное оборудование; собственная лаборатория качества; экологичные материалы; преимущества тепло/прочность/экономия/поддержка; калькулятор; проекты; контакты; header/footer.

## Калькулятор
Сейчас: площадь стены / площадь блока + 5% запас. Если в старом калькуляторе была другая формула, меняется только calculate() в js/main.js.

## Фото
В ранее созданном архиве не было локальных фотографий клиента, были только внешние Unsplash URL. Поэтому они сохранены как URL. Перед публикацией заменить их на реальные фото Сергея. Папка assets/images уже создана.
